# 🧠 Хитрый купец

## 📌 Описание проекта

**«Хитрый купец»** — это консольное приложение на C++, реализующее задачу с циклическим обходом структуры данных.

Два купца отправились торговать за море, каждый взял по **N одинаковых тюков** с товаром (всего `2N`).

Во время шторма капитан вынужден выбрасывать половину груза по строго заданному правилу.

👉 Задача:  
**найти такие позиции для тюков одного из купцов, чтобы ни один его тюк не был выброшен за борт.**

---

## ⚙️ Правила задачи

Тюки располагаются по кругу и нумеруются следующим образом:

- 📦 Всего тюков: `2 * N`
- 🔢 Нумерация начинается с носа корабля
- ⏱ Стартовая позиция: `M` (число месяца, 1–31)
- 🔁 Каждый шаг: выбрасывается каждый `K-й` тюк
- 🌊 Удаляется ровно `N` тюков (половина груза)
- ⭕ Обход осуществляется по кругу (циклический список)
