## Суть задачи

**«Хитрый купец»** — это программная реализация задачи на циклический обход элементов.

### Легенда
> Два купца отправились торговать за море. Каждый взял по **N одинаковых тюков** с товаром (всего `2N` тюков).  
> В пути корабль попал в шторм и дал течь. Капитан приказал поднять груз на палубу, расставить вдоль бортов по периметру и выбросить **ровно половину груза** по строгому правилу.

### Правило выбрасывания

| Правило | Описание |
|---------|----------|
| **Всего тюков** | `2 × N` (N тюков у каждого купца) |
| **Нумерация** | По часовой стрелке, начиная с носа корабля |
| **Стартовая позиция** | `M` — число месяца (1–31) |
| **Шаг** | Выбрасывается каждый `K+1`-й тюк |
| **Количество выбрасываний** | Ровно `N` тюков (половина) |

## Описание классов и функций

### 1. Класс `Node` (узел списка)

| Функция | Что делает |
|---------|------------|
| `Node()` | Конструктор по умолчанию, создаёт узел с data=0 |
| `Node(int value)` | Конструктор, создаёт узел с заданным значением |
| `int getData()` | Возвращает данные узла |
| `void setData(int value)` | Устанавливает данные узла |
| `Node* getNext()` | Возвращает указатель на следующий узел |
| `void setNext(Node* nextNode)` | Устанавливает указатель на следующий узел |

---

### 2. Класс `Linked_cyclic_list` (циклический список)

| Функция | Что делает |
|---------|------------|
| `Linked_cyclic_list()` | Конструктор, создаёт пустой список |
| `~Linked_cyclic_list()` | Деструктор, удаляет все узлы и освобождает память |
| `Linked_cyclic_list(const Linked_cyclic_list& other)` | Конструктор копирования |
| `void PushBack(int value)` | Добавляет элемент в конец списка |
| `void Remove(Node* oldNode)` | Удаляет указанный узел из списка |
| `void Print()` | Выводит все элементы списка |
| `Node* getHead()` | Возвращает указатель на голову списка |
